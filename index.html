Fundamentos

Introducción a PostgreSQL

Bienvenido al manual interactivo del SGBD Open Source más avanzado.

Bienvenido al manual y guía interactiva de PostgreSQL. Este documento te guiará desde los conceptos fundamentales hasta técnicas avanzadas de rendimiento y seguridad.

Setup

Instalación

Guía para tener PostgreSQL corriendo en minutos.

bash 
# Ubuntu/Debian
sudo apt update
sudo apt install postgresql postgresql-contrib

# macOS (Homebrew)
brew install postgresql
Teoría

Conceptos Básicos

Modelo relacional vs Objeto-relacional.

A diferencia de los SGBD relacionales convencionales, PostgreSQL es un sistema gestor de bases de datos objeto-relacional (ORDBMS). Permite herencia de tablas y tipos de datos personalizados.

Desarrollo

Consultas SQL

Potencia de CTEs y funciones de ventana.

PostgreSQL soporta el estándar SQL de manera estricta y añade numerosas extensiones potentes.

sql 
WITH VentasRegionales AS (
    SELECT region, SUM(monto) as total_ventas
    FROM ordenes
    GROUP BY region
)
SELECT region, total_ventas
FROM VentasRegionales
WHERE total_ventas > (SELECT SUM(total_ventas)/10 FROM VentasRegionales);
Desarrollo

Funciones

Lógica de negocio en la BD.

PostgreSQL permite escribir funciones en múltiples lenguajes: SQL, PL/pgSQL, C, Python, etc.

Desarrollo

Procedimientos Almacenados

Control avanzado de transacciones.

A partir de la versión 11, PostgreSQL introdujo procedimientos que permiten el control de transacciones (COMMIT/ROLLBACK) directamente desde el código del procedimiento.

Arquitectura

Diseño de Base de Datos

Mejores prácticas y tipos JSONB.

Utiliza restricciones (constraints), normalización adecuada y el uso de tipos de datos JSONB para esquemas híbridos y flexibles.

Arquitectura

Seguridad

Protege tus datos y conexiones.

Nunca conectes aplicaciones con el usuario `postgres`. Crea roles con mínimos privilegios (Principio de Menor Privilegio) y configura `pg_hba.conf` para restringir conexiones.

Avanzado

Rendimiento y EXPLAIN

Optimización a nivel de planificador.

Analiza el costo de las consultas utilizando EXPLAIN ANALYZE. Comprender el plan de ejecución es fundamental para optimizar índices.

-> Hash Join (cost=2.03..2.06 rows=1)
-> Seq Scan on t1
-> Hash
-> Seq Scan on t2
